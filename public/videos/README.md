# Videos

Add `zovive-intro.mp4` and `zovive-intro-poster.jpg` here once the final video is ready.

These are referenced by the Intro Video section on the Home page
(`src/components/home/IntroVideo.jsx`):

- `zovive-intro.mp4` — the video file, referenced via `<source src="/videos/zovive-intro.mp4" />`
- `zovive-intro-poster.jpg` — static thumbnail shown before playback, referenced via the `<video poster="...">` attribute

No code changes are needed once both files are dropped in here — the paths are already wired up.
